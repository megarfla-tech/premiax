
# PremiaX

**Sua chance. Seu próximo prêmio.**

A PremiaX é uma plataforma em desenvolvimento para campanhas de premiação, com área pública, área do participante e painel administrativo.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Supabase
- Netlify

## Funcionalidades previstas

- Cadastro e autenticação de participantes
- Campanhas e categorias
- Seleção manual de números
- Reservas de números
- Histórico de pedidos
- Painel administrativo
- Auditoria e transparência dos resultados

## Segurança

- Supabase com Row Level Security (RLS).
- Chave publishable no frontend.
- Operações críticas protegidas no backend.
- Nenhuma chave secreta deve ser publicada.

## Estado do projeto

Em desenvolvimento. Recursos comerciais e pagamentos reais permanecerão desativados até a validação legal, operacional e de segurança.
